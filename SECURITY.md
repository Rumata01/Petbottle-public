# Güvenlik Politikası

## Güvenlik Açığı Bildirimi

Lütfen güvenlik açıklarını herkese açık "Issues" kısmına yazmayın.

Bunun yerine, GitHub'ın **"Report a vulnerability"** butonunu kullanın:
1. "Security" sekmesine gidin.
2. "Advisories" kısmına tıklayın.
3. "New draft security advisory" butonunu kullanarak bize özel mesaj gönderin.
